## v0.5.0 · 中英两种语言，Mac 上有了自己的 app，新 Mac 一行装好

这一版回应的几条需求：整个界面都能切到英文（双语支持）；录便条时屏幕上能看到 1 到 9 各是哪个项目；语音先进 Mac，再由你交给不同的 agent；新 Mac 最好一条 curl 就能装好。

设备、cpad 和新的 Mac app 一起发。协议 v0 只新增：新旧固件和新旧 cpad 可以任意搭配；录音契约 v1 只新增（`env{host, link}`）。WhisperWoof 照旧能用。

### 设备
- **整个设备能切到 English**（docs/21）：Opt+M 打开新的"设置 / Settings"页，光标停在 WiFi 行；按 `.` 到"语言 Language"，Enter 一下在中文和 English 之间切换（Opt+M、`.`、Enter 三下）。主页、看板、等你（英文叫 Inbox）、编辑器、确认框、录音页、锁屏卡、状态栏、Tab 菜单、所有提示和 Mando 的牌子都有两套字，每一对都在编译时查过字形和宽度；中文界面一个像素都没变。设置页还写着 USB 线连着哪台 Mac、上次同步多久以前，右边一页（`/`）是诊断。
- **录音时屏幕上一直写着 1–9 是哪个项目**（gh #53）：便条页和会议页按键盘数字那一排的顺序写 `[1] 项目 … [9] 项目 [0] 不归属`，现在选的那个亮着，按数字的那一刻就换过去。项目多时先多占一行，放不下才把键截成一样长。便条页不再单写"存到 #项目"，亮着的就是去向。
- **Mando 藏了几个小彩蛋**。不告诉你全部，只给三个提示：他喜欢被摸（主页上找找哪个组合键还空着）；他知道现在几点、今天星期几（熬夜和周末都看看锁屏卡）；等你的事全处理完的那一刻，看一眼主页。录音时它们从不出来，也不写卡。答案在 docs/04 最后的"隐藏按键"里。
- 固件版本报 `cpa-fw/0.5.0`。

### Mac 上
- **Cardputer Assistant for Mac**（docs/24）：自己的原生 app，一个窗口（待归档 · 录音 · 设备 · 项目 · 集成 · 设置）加菜单栏上 Mando 的头。待归档里 1–9 一下归档，⌘Z 撤销，交给 AI、看过了、藏起来、播放。它只用公开接口（`cpa … --json`、笔记目录、`cpa mcp`），不联网，代码里不出现任何 app 的名字。
- **App 有 English**：跟着系统语言，设置里也能选。
- **项目在 Mac 上建**（docs/25 D24）：项目现在是有名字的分组，不一定要代码目录（名字可以是中文）。App 的"项目"页和设备一样是 1–9：新建、改名、点编号或拖动换号、连一个文件夹、删除；命令行是 `cpa project add -- 名字`、`rename`、`move`、`folder`、`rm`。
- **待归档清零时有个小回顾**：最后一条归完，菜单栏的状态点闪一下，空的待归档里 Mando 跳三下，下面是今天的便条数、分钟、去了几个项目、★。
- **Vlog 时间码**：录音详情里"复制为 Vlog 时间码"，有 ★ 时只列带 ★ 的那几句（YouTube 章节认得），还能导出 SRT。
- **从 Mac 把便条送进 Grok Bot**（docs/25 R1）：`cpa dest add --preset grok-bot` 加上去向，`cpa dest test url.grok --send` 先送一条测试并问你"出现了吗、自动发了吗"；之后在 app 的待归档上面"等你送"里按 ⌘↩，或者 `cpa filing send ID url.grok`，便条正文就进了 Grok 的输入框，**你在 Grok 里按回车才发出**。太长时走剪贴板（2 分钟后清掉）。设备上直接送是以后的事（R2）。
- **本机转写 `cpa-stt`**（docs/22）：在这台 Mac 上转写录音，不联网，默认关；`cpa-stt setup` 找已有的模型，`cpa-stt use` 打开。`cpa setup check` 里有一行说它好没好。
- `cpa filing`、`cpa filing triage`：在终端里一条一条过待归档，一个键一个动作。
- `cpa setup check [--todo]`：这台 Mac 还差哪几步，中英文。
- 版本号跟 tag：`cpa --version`、`cpa-stt --version`、app 都是 0.5.0，uv 不再装回旧的 0.1.0（#57）。

### 一行装到新 Mac（docs/27）

需求：新系统要能在另一台 Mac 上顺利装好，最好一条 curl 就装上。

```bash
curl -fsSL https://raw.githubusercontent.com/h3qing/cardputer-assistant/main/scripts/install.sh | bash
```

U 盘：主力 Mac 上 `scripts/release-local.sh --tag v0.5.0 --out /Volumes/USB/v0.5.0 --release-json`，新 Mac 上 `bash /Volumes/USB/v0.5.0/install.sh --from /Volumes/USB/v0.5.0`。

再跑一次就是升级。

- 每个下载的文件都核对 GitHub 的 SHA-256 和本发布的 `SHA256SUMS`；对不上什么都不装。
- `cpa` 装成 uv 工具（`~/.local/bin`），app 进 `~/Applications`，不用 sudo，不碰 Gatekeeper。
- **装后台服务前先问你**设备在主力 Mac 上同步过没有（今天的 cpad 插上就接管设备上没传的笔记和录音）。
- 不碰 `~/.claude`、笔记、`$CPA_HOME`；`config.json` 只更新 `spawn_env`、`claude_bin`。
- 下载有进度条；最后一屏是一张中英文清单（`cpa setup check --todo`），只列还没好的、标出必需的。
- 卸载：`uninstall.sh`，留着你的数据。

### 已知问题
- **多台 Mac：插到另一台 Mac 之前，先在主力 Mac 上同步完**。今天任何一台连上的 Mac 都会把设备上还没传的录音全部拉走，设备随后删掉自己的那份；拉错了 Mac，另一台就拿不到了。插上主力 Mac、等 `↑0`、录0 以后再去插别的 Mac。docs/28 的 S1（插上时的提示和留底）做完以前一直是这样。安装脚本在装后台服务前也会问你这件事。
- **GitHub Actions 停着**：上面的检查都是本机跑的；Actions 恢复后再在 GitHub 上跑一遍。
- **彩蛋在真机屏幕上的样子还没人看过**：真机上只查了它们不碍事（见上面的验证）；画面是在模拟器截图里看的。按时钟的心情要等到深夜、清早或周末，你会先看到。
- **WhisperWoof 还不认 `cpa-stt` 的认领文件**（docs/22 §4.10）：两个只能开一个；开 `cpa-stt` 前先关 WhisperWoof 的 Cardputer 收件箱。
- **Grok Bot 只填草稿**：按回车发出的永远是你；设备上直接送（R2）暂缓。
- v0.4.1 列出的真机闸门（揣着过一天、按你的手速开一场真会、拔插 SD 卡）还要你来做。
