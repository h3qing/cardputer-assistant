## v0.1.0 · USB 闭环 MVP

这是 Cardputer ADV 口袋工作助手的第一个可用版本：设备通过 USB 连着 Mac，在 Claude Code 的项目看板、"等你"收件箱和速记之间形成闭环。

### 功能
- **速记**：按 G0 打开输入框，打字后按 Enter 保存，内容先存在设备的 LittleFS outbox 里，再同步到 Mac 的 `~/CardputerNotes/YYYY-MM-DD.md`。断线期间存下的条目，连上后会自动补发，不会丢，也不会重复。
- **项目看板**：daemon 每 3 秒读一次 `claude agents --json`，按项目把 session 分组，显示运行中、等你、排队的数量。中文 session 名能正常显示（efontCN_12 字库）。
- **"等你"收件箱和项目队列**：反馈先进队列；可以给项目开新 session，默认 `plan` 权限模式，正文前面一律加 `--`。离线时发起的开 session 请求只会变成排队项，联网后不会自动执行。
- **Mac daemon `cpad` / 命令行 `cpa`**：Python 3.12，运行时只依赖 pyserial；以 LaunchAgent 方式常驻；所有事件写进只追加的 `events.jsonl`。

### 验证
- 固件：215 个 native 测试，纯逻辑代码覆盖率 96%；编译期栈预算检查和资源预算检查都通过（静态 RAM 59KB，app 841KB）。
- daemon：548 个测试，覆盖率 96.7%。协议契约：19 种消息、8 条流程、211 个测试向量。
- 真机 HIL：10 个场景全部通过，包括握手不复位、速记闭环、离线补发、丢 ack 去重、重启后重新同步、看板、开 session 的参数、离线开 session 变成排队、延迟、中文显示；另外连续跑了 10 分钟，没有丢失或重复。

### 产物
- `cpa-fw-v0.1.0-cardputer-adv-full.bin`：整片镜像，从 0x0 开始烧，例如 `esptool.py --chip esp32s3 write_flash 0x0 <file>`
- `cpa-fw-v0.1.0-cardputer-adv-app.bin`：只有 app 部分，从 0x10000 开始烧
- `SHA256SUMS`

### 已知问题
- outbox 存满 200 条时，保存耗时的 p95 是 108–158ms，比 100ms 的目标略慢。没存满时在 87ms 以内。
- 13 项手动检查还没做（打字准确率、真实断电、60 分钟长测等），见 `docs/07-hil-checklist.md`。
- `CPA_HOME` 路径太长时 daemon 会直接退出，只报一句 `AF_UNIX path too long`。默认路径不受影响。
- 本版不支持语音、WiFi/BLE、在设备上审批、回复 interactive session。
