## v0.5.1 · 录音等对的 Mac 来拿；英文为主，也支持中文

这一版回应一条需求：给另一台 Mac 的录音，不能因为先插了这台 Mac 就没了。设备现在交出录音后留一份底，可以再交给另一台 Mac；插上时有离线录的录音，会先停一下问你。另外，文档、`cpa`、安装脚本和 Mac app 改成英文为主、也支持中文，并修了安装脚本装后台服务时的竞争。

设备、cpad 和 Mac app 一起发。协议 v0 没变；留底只在设备上，新旧固件和新旧 cpad 可以任意搭配。WhisperWoof 照旧能用。

### 设备：录音留到对的 Mac（docs/28 S1a，#84）
- **留底**：Mac 拉走一段录音时，设备不再删掉它，而是在 SD 卡的交付账本（`SENT.L`：哪段录音交给了哪台 Mac，记 4 字节的哈希）里写一行，文件再留 7 天。留底对所有 Mac 都看不见，也不占 256 段的待传。卡上空闲不到 1 GB、或段数超过开机扫描放得下的数目时，从最旧的删起。
- **再交一次**：设置 → 存储（Opt+M 再按 `,`）→"再交一次"。这一行写着最近一批交给了哪台 Mac（"·3F2A 的 2 次"）；确认框光标在"取消"，`/` Enter 确认。这一批重新待传，**拿走它的那台 Mac 以后再也看不到它们**：下一台插上的别的 Mac 来拿。
- **给这台 Mac**：设置 → 存储的第二行，撤回"再交一次"（和下面提示里的"不给"），连着的这台 Mac 又能拿到被扣下的那些。
- **插上时的提示**：上次拔线以后录过音，再插上 Mac 时，提示栏 5 秒里写"离线 2 条 → 这台 · Tab 不给"。什么都不按就照常给；Tab 再 Enter 就不给这台。锁着或开着 Tab 菜单时提示看不见，5 秒就不走，这几条一直扣着，最多 2 分钟。
- **清掉留底**：设置 → 存储 →"清掉留底"，确认框光标在"取消"。有留底时，锁屏卡片和设置页的同步行写"留N"。**留底在卡上是明文**（SECURITY.md）：带设备去不信任的地方之前，先同步清零，再清掉留底。
- 快速换 Mac 也没问题：从一台 Mac 拔下马上插到另一台，新的这台现在立刻就拉（真机上发现、修好之前要等 60 秒）。
- 固件版本报 `cpa-fw/0.5.1`。

### 英文为主，也支持中文（#88–#92）
- **文档**：英文在原来的路径，中文在旁边的 `*.zh-CN.md`，第一行是语言切换（CONTRIBUTING）。这一版把 CHANGELOG、SECURITY、docs/07、docs/28 和 `firmware/sim/README.md` 也翻了。
- **`cpa`、cpad 和 cpa-stt** 默认说英文，语言说是中文时才说中文：先看 `CPA_LANG`，再看 `cpa lang zh|en|auto`（`config.json` 的 `lang`），再看 Mac 的区域设置。原来只有中文、或中英并排的 `cpa filing triage`、`cpa dest test --send`、`cpa setup check` 现在只用一种语言。每日笔记的行、会议标题、去向名字用写的那一刻的语言；写过的行不会改写。`cpa service install` 把区域设置带给后台服务。
- **安装脚本**：`install.sh` 和 `uninstall.sh` 只出一种语言，默认英文；`--lang zh`（或 `CPA_LANG=zh`、中文的区域设置）就是中文。最后那张清单跟着它。
- **Mac app**：截图英文画到 `out/shots/`，中文画到 `out/shots/zh/`，演示数据是英文的。app 本身本来就有两种语言。
- **HIL 工具**：注释改成英文；读不到开始时的语言时，跑完把设备设回英文。

### 其他
- **安装脚本：后台服务不再和旧的抢**（#83）。`cpa service install` 先等旧的 cpad 停下，再确认新的真在跑，不行就再试一次，还不行就停下来说清楚；`install.sh` 只信这个结果。
- **设计稿：空闲休眠**（docs/29，#86）：电池供电、熄屏时浅睡，2 小时后深睡，电量低时关机。只是设计，这一版固件里没有。

### 升级
- **Mac 上**：再跑一次安装的那一行命令（README"安装"）；再跑一次就是升级：

  ```bash
  curl -fsSL https://raw.githubusercontent.com/h3qing/cardputer-assistant/main/scripts/install.sh | bash
  ```

  要中文输出就加 `bash -s -- --lang zh`。
- **设备**：刷这个发布里的 `cpa-v0.5.1.bin`（`… | bash -s -- --firmware` 也会核对好、放进 `~/Downloads`）。在主力 Mac 上：先同步（`↑0`、录0），`cpa pause 120`，再照 README"安装方式 A"写到 0x0。写合并镜像会擦掉 NVS，所以语言这类设置回到默认值；SD 卡上的录音和留底不受影响。

### 已知问题
- **"再交一次"或"清掉留底"时可能被任务看门狗重启**：大约 100 段待传、200 段留底时会出现。数据是安全的：设备重启，什么都不丢。遇到了就先同步、让待传少一些，再做一次。#85 修了它。
- **留底是明文**，直到 SEAL 加密（docs/26）做出来；去不信任的地方之前先清掉（SECURITY.md）。
- **GitHub Actions 停着**：上面的检查都是在本机跑的。Actions 恢复以后在 GitHub 上再跑一遍。
- **WhisperWoof 还不认 `cpa-stt` 的认领文件**（docs/22 §4.10）：两者只能开一个。
- v0.4.1 列出的真机闸门（揣一天、按你自己的节奏真开一次会、拔插 SD 卡）仍要你来做。
