# 0003 · 录音不出声；会议确认框和 `consent:"ack"` 保留；录音时 ● 永远看得见

- 状态：已接受
- 日期：2026-10-21
- 相关：[11 §2、§3.2、§4.2、§9](../11-m3-design.zh-CN.md)、[13 §7.2–§7.4、§18 第 1 条](../13-assistant-v2-plan.zh-CN.md)、[04 §8.6、§8.8](../04-prd.zh-CN.md)、`lib/shell/rec_overlay.cpp`、`lib/shell/power.h`、`lib/shell/lock_screen.cpp`、issue #17

## 背景

- **旧规则**（v0.3.0，11 §2 的裁决表、§4.2、§9）：录音提示音**不能关**。便条开始"嘀"、保存"嘟"；会议开始和结束各响一串约 360 ms 的三声提示音，和便条明显不同。理由是让在场的人听得到（📚 granola-pipeline.md §6.6：加州录私下谈话要所有参与方同意）。
- **用户的决定**（2026-10-21）：关掉录音提示音；录音不出声，设备是个人自用的。v0.3.1 起录音全程不出声（11 开头和各处的"2026-10-21 起改为"注记）。
- 去掉声音以后，屏幕是设备上唯一的提示，旁人只能靠用户当面告知。

## 候选方案

| 方案 | 优点 | 缺点 | 证据 |
|---|---|---|---|
| A 保留提示音，不能关（v0.3.0） | 旁人听得到 | 用户明确不要；设备是个人自用的 | 11 §4.2 |
| B 全程不出声；会议确认框保留并记录；录音时屏幕一直显示 ● | 符合用户决定；会议前仍有一次有意的确认，留有记录 | 旁人察觉不到，告知全靠用户 | v0.3.1 已发布 |
| C 加声音设置（便条"嘀"关 / 轻，会议在任何设置下都不响） | 以后可选 | 要一个存盘的设置项和静音键；用户没有要 | 13 §7.3、§18 第 1 条的备选 |

## 判定规则

- 单人设备，个人自用：用户的决定优先。
- 会议录音开始前必须有一次按键确认，并且写进录音的元数据。
- 录音时屏幕上必须一直看得出在录：锁屏、Tab 菜单、弹提示、背光调暗都不能把 ● 藏掉（`test_rec_visible` 检查每一种组合）。

## 决定

选 **B**。

1. **不出声**（v0.3.1）：便条开始和已保存、会议开始和已保存、太短或取消、拒绝或失败都不响。v0.4 不加静音键和音量档位，菜单"控制"页只读地写"声音 关（录音不出声）"。
2. **会议确认框保留，文案用 v0.3.1 的原样**（`render_meeting_confirm`）：

   ```
   开始会议录音？
   请先告知在场的人
   Enter 开始    ` 取消
   ```

   打开后 400 ms 内的按键一律忽略。13 §7.4 提过一版写明责任在用户的新文案，用户还没有同意，v0.4.0 不用；以后要换，另写一篇 ADR 取代这一条。
3. **记录确认**：在确认框里按 Enter 开始的会议，第 0 段的 `.M` 和会话的 `manifest.json` 写 `consent:"ack"`（11 §4.4、§7.3）。它只表示"用户确认过已经告知在场的人"，不代表别人同意。便条不弹确认框，没有这个字段。
4. **● 规则**（v0.4.0，13 §7.2）：RecPhase 是 Cue、Recording、EndConfirm 或 Finishing 时，背光最暗只到"调暗"，并且画出 ● 和计时，锁屏、Tab 菜单打开、弹提示时都一样。锁屏时开会，左上角只有一行"●42:10 ★2"；锁屏时录便条，麦克风打开前是"● 准备"，之后是"● REC 0:12"。

## 后果

- 好处：符合用户的用法；会议前仍有一次有意的确认，事后有 `consent:"ack"` 可查；屏幕一直告诉用户（和看得到屏幕的人）设备在录。
- 代价和风险：在场的人听不到任何提示；口袋里误录也察觉不到。对策是锁屏时"先点一下 G0、卡片亮着再按住"才录（13 §7.1），不到 1 s 的便条自动丢弃（11 §4.2）。告知并取得同意由用户负责，README 写明这一点，并说明不构成法律意见。
- 退路：用户以后想要声音，按 13 §18 第 1 条的备选加"便条提示音：关 / 轻"，会议在任何设置下都不响；设备要给别人用、或者要录别人时，重新评估方案 A。
- 需要同步修改的文档或代码：11（2026-10-21 的就地注记，§4.1 和 §9 指向本文）；README 的"录音和同意"；04 §8.6、§8.8；测试 `test_rec_overlay`（确认框文案和 400 ms 保护）、`test_rec_visible`（● 规则）、`test_lock_power`（锁屏时的 G0）。
