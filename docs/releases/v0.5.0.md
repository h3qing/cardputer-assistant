## v0.5.0 · Two languages, a Mac app of its own, one-line install on a new Mac

This release answers a few requests: the whole interface can switch to English (bilingual support); while recording a memo, the screen shows which project each of 1–9 is; voice goes to the Mac first, and you then hand it to different agents; a new Mac should install with a single curl.

The device, cpad and the new Mac app ship together. Protocol v0 is additive only: old and new firmware and old and new cpad mix freely. Recording contract v1 is additive only (`env{host, link}`). WhisperWoof keeps working.

### Device
- **The whole device can switch to English** (docs/21): Opt+M opens the new Settings page (shown as "设置 / Settings"), with the cursor on the WiFi row. Press `.` to reach "Language" (shown as "语言 Language"); one Enter toggles between 中文 and English (three presses: Opt+M, `.`, Enter). Home, the board, Inbox (等你 in Chinese), the editor, confirm dialogs, the recording page, the lock card, the status bar, the Tab menu, every hint and Mando's signs all have two sets of text. Every pair is checked for glyphs and width at compile time. The Chinese interface did not change by a single pixel. The Settings page also shows which Mac the USB cable is connected to and how long ago the last sync was. The page to the right (`/`) is diagnostics.
- **While recording, the screen always shows which project each of 1–9 is** (gh #53): the memo page and the meeting page list `[1] project … [9] project [0] none` in the order of the number row. The current one is highlighted, and it switches the moment you press a digit. With many projects it first takes an extra line, and only truncates the keys to equal width when that is not enough. The memo page no longer has a separate "Save to #project" line; the highlighted project is the destination.
- **Mando hides a few small easter eggs.** Not all of them are told here, only three hints: he likes being patted (look on Home for a key combination that is still free); he knows the time and the day of the week (look at the lock card late at night and on weekends); and look at Home the moment everything in your Inbox is handled. They never appear while recording, and they never write to the card. The answers are in "Hidden keys" at the end of docs/04.
- The firmware reports `cpa-fw/0.5.0`.

### On the Mac
- **Cardputer Assistant for Mac** (docs/24): a native app of its own, one window (To file · Recordings · Device · Projects · Integrations · Settings) plus Mando's head in the menu bar. In To file, 1–9 files an item in one press, ⌘Z undoes, and you can hand to AI, mark seen, hide or play. It only uses public interfaces (`cpa … --json`, the notes folder, `cpa mcp`), never goes online, and no app name appears in its code.
- **The app has English**: it follows the system language and can be set in Settings.
- **Projects are created on the Mac** (docs/25 D24): a project is now a named group, not necessarily a code folder (the name may be Chinese). The app's Projects page uses 1–9 just like the device: create, rename, click the number or drag to change slots, link a folder, delete. On the command line: `cpa project add -- name`, `rename`, `move`, `folder`, `rm`.
- **A small recap when To file reaches zero**: when the last item is filed, the status dot in the menu bar blinks once, Mando jumps three times in the empty To file, and below it are today's memo count, minutes, how many projects they went to, and ★.
- **Vlog timecodes**: in recording details, "Copy as Vlog timecodes". With ★ it lists only the starred sentences (YouTube recognises them as chapters). It can also export SRT.
- **Send memos from the Mac to Grok Bot** (docs/25 R1): `cpa dest add --preset grok-bot` adds the destination. `cpa dest test url.grok --send` first sends one test and asks you "did it appear, did it send by itself". After that, press ⌘↩ in "Waiting to send" above To file in the app, or run `cpa filing send ID url.grok`, and the memo text lands in Grok's input box. **It is only sent when you press Return in Grok.** Long text goes through the clipboard (cleared after 2 minutes). Sending straight from the device comes later (R2).
- **Local transcription `cpa-stt`** (docs/22): transcribes recordings on this Mac, offline, off by default. `cpa-stt setup` finds existing models; `cpa-stt use` turns it on. `cpa setup check` has a line saying whether it is ready.
- `cpa filing`, `cpa filing triage`: go through To file in the terminal one item at a time, one key per action.
- `cpa setup check [--todo]`: which steps this Mac still lacks, in Chinese and English.
- Version numbers follow the tag: `cpa --version`, `cpa-stt --version` and the app are all 0.5.0; uv no longer reinstalls the old 0.1.0 (#57).

### One-line install on a new Mac (docs/27)

Requirement: the new system should install cleanly on another Mac, ideally with a single curl.

```bash
curl -fsSL https://raw.githubusercontent.com/h3qing/cardputer-assistant/main/scripts/install.sh | bash
```

Running it again upgrades. From a USB stick: on the main Mac, `scripts/release-local.sh --tag v0.5.0 --out /Volumes/USB/v0.5.0 --release-json`; on the new Mac, `bash /Volumes/USB/v0.5.0/install.sh --from /Volumes/USB/v0.5.0`.

- Every downloaded file is checked against GitHub's SHA-256 and this release's `SHA256SUMS`. On a mismatch nothing is installed.
- `cpa` is installed as a uv tool (`~/.local/bin`), the app goes to `~/Applications`. No sudo, no Gatekeeper changes.
- **Before installing the background service it asks you** whether the device has synced on the main Mac (today's cpad takes over the notes and recordings not yet transferred from the device as soon as it is plugged in).
- It does not touch `~/.claude`, your notes or `$CPA_HOME`. In `config.json` it only updates `spawn_env` and `claude_bin`.
- Downloads show a progress bar. The last screen is a checklist in Chinese and English (`cpa setup check --todo`) that lists only what is not ready yet and marks what is required.
- Uninstall: `uninstall.sh`, which keeps your data.

### Known issues
- **Several Macs: before plugging into another Mac, finish syncing on the main Mac.** Today any Mac that connects pulls every recording not yet transferred from the device, and the device then deletes its own copy. If the wrong Mac pulls them, the other one never gets them. Plug into the main Mac, wait for `↑0` and R0, then plug into another Mac. This stays so until S1 in docs/28 (a prompt on plug-in, and kept copies) is done. The installer also asks you about this before installing the background service.
- **GitHub Actions is suspended**: all the checks above ran locally. Run them again on GitHub once Actions is back.
- **Nobody has looked at the easter eggs on the real device's screen yet**: on the real device we only checked that they stay out of the way (see Verification). The visuals were reviewed in simulator screenshots. The clock-based moods need late night, early morning or a weekend; you will see them first.
- **WhisperWoof does not yet recognise `cpa-stt`'s claim file** (docs/22 §4.10): only one of them can be on. Turn off WhisperWoof's Cardputer inbox before turning on `cpa-stt`.
- **Grok Bot only fills a draft**: you are always the one who presses Return to send. Sending straight from the device (R2) is on hold.
- The real-device gates listed in v0.4.1 (carry it for a day, run a real meeting at your own pace, pull and reinsert the SD card) still need you.
