## v0.5.2 · 默认英文、黑屏时会歇着、大批清理不再触发看门狗

这一版把 v0.5.1 等设备测试的几件事做完：开机扫描的栈和任务看门狗修复（#85）、暗屏少转（#87）、设备默认英文（#94）。三个都先在真机上测过再合并（docs/07 §12）。另外修了安装脚本的 "Broken pipe" 噪音（#98）。

设备、cpad 和 Mac app 一起发。协议 v0 不变，新旧固件、新旧 cpad 可以随便混用。WhisperWoof 照常能用。

### 设备
- **默认英文**（#94）：什么都没存的设备（新的，或者 NVS 擦过的）用英文开机。跑过旧版 cpa-fw、从来没切换过的设备保持中文：它第一次用这个固件开机时把中文存一次。已经选过的语言不会动；Opt+M、`.`、Enter 照样切换。
- **用电池黑屏时会歇着**（#87，docs/29 P1）：黑屏并锁上、没在录音、没插 Mac、1 秒内没按键时，主循环每一轮后让出 CPU 10 ms，不再 240 MHz 空转：每秒 98 轮，原来约 14,400 轮。按键最多晚 10 ms；亮屏、调暗、录音、插着 Mac 时完全照旧。
- **大批清理不再触发看门狗重启**（#85，v0.5.1 的已知问题）：对几百段留底「再交一次」「清掉留底」时，不再饿着 core 0 的空闲任务。真机上 200 段 5.7 s 排回、14.2 s 清完。
- **开机时音频任务的栈更宽裕**（#85）：卡上有约 100 条录音等着时，开机扫描后音频任务 6 KB 的栈只剩 1,028 B；现在剩 1,624 B（闸是 1,536 B）。别的都没变：堆、静态 RAM、栈大小。
- 固件和模拟器的代码注释改成英文（只有讲中文本身的注释还是中文）。
- 固件版本报 `cpa-fw/0.5.2`。

### Mac
- **安装脚本**：curl 安装时不再冒出 "printf: write error: Broken pipe"（#98）。它不影响安装（装是装好了），但看着吓人。
- 安装说明只给公开的 `curl … | bash` 一行（#97）。
- `cpa --version`、`cpa-stt --version` 和 Mac app 都是 0.5.2。Mac 上没有别的变化。

### 升级
- **Mac 上**：再跑一次安装那一行（README「安装」）；再跑一次就是升级：

  ```bash
  curl -fsSL https://raw.githubusercontent.com/h3qing/cardputer-assistant/main/scripts/install.sh | bash
  ```

  加 `bash -s -- --lang zh` 输出中文。
- **设备**：刷这次发布里的 `cpa-v0.5.2.bin`（`… | bash -s -- --firmware` 也会校验它，并放进 `~/Downloads`）。在主力 Mac 上：先同步（`↑0` 和 R0），`cpa pause 120`，然后照 README「安装方法 A」写到 0x0。写合并镜像会擦掉 NVS，设置回到默认，现在默认是**英文**；SD 卡上的录音和留底不受影响。Opt+M、`.`、Enter 切回中文。

- 安装脚本：沙盒测试 146/146（临时 HOME，假的 launchctl / open），包括塞了约 2 MB 资产、忽略 SIGPIPE 的发布，以及没有 `~/Library/LaunchAgents` 的 HOME。
