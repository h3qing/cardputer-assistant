## v0.1.0 · USB closed-loop MVP

This is the first usable version of the Cardputer ADV pocket work assistant. The device is connected to the Mac over USB, and it closes the loop between Claude Code's project board, the "waiting on you" inbox and quick notes.

### Features
- **Quick notes**: press G0 to open the input box, type, and press Enter to save. The entry is first stored in the device's LittleFS outbox, then synced to `~/CardputerNotes/YYYY-MM-DD.md` on the Mac. Entries saved while disconnected are sent automatically after reconnecting, with no loss and no duplicates.
- **Project board**: the daemon reads `claude agents --json` every 3 seconds, groups sessions by project, and shows how many are running, waiting on you and queued. Chinese session names display correctly (efontCN_12 font).
- **"Waiting on you" inbox and project queue**: feedback goes into a queue first. You can start a new session for a project; the default permission mode is `plan`, and the body is always prefixed with `--`. A start-session request made while offline only becomes a queued item; it does not run automatically once back online.
- **Mac daemon `cpad` / command line `cpa`**: Python 3.12, only depends on pyserial at runtime; runs as a LaunchAgent; all events are written to an append-only `events.jsonl`.

### Verification
- Firmware: 215 native tests, 96% coverage of pure-logic code; the compile-time stack budget check and resource budget check both pass (static RAM 59KB, app 841KB).
- Daemon: 548 tests, 96.7% coverage. Protocol contract: 19 message types, 8 flows, 211 test vectors.
- Real-device HIL: all 10 scenarios pass, including handshake without reset, quick-note loop, offline resend, dedup on lost ack, resync after reboot, board, start-session arguments, offline start-session becoming a queued item, latency and Chinese display. A further 10-minute continuous run showed no loss or duplicates.

### Artifacts
- `cpa-fw-v0.1.0-cardputer-adv-full.bin`: full image, flash from 0x0, e.g. `esptool.py --chip esp32s3 write_flash 0x0 <file>`
- `cpa-fw-v0.1.0-cardputer-adv-app.bin`: app only, flash from 0x10000
- `SHA256SUMS`

### Known issues
- With the outbox full at 200 entries, p95 save time is 108–158ms, a bit slower than the 100ms target. When not full it is within 87ms.
- 13 manual checks are not done yet (typing accuracy, real power loss, 60-minute long test, etc.); see `docs/07-hil-checklist.md`.
- When `CPA_HOME` is too long, the daemon exits right away with only `AF_UNIX path too long`. The default path is not affected.
- This version does not support voice, WiFi/BLE, approving on the device, or replying to interactive sessions.
