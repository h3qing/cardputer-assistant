## v0.4.0 · 整机导航：主页、Tab 菜单、锁屏

这一版让 Cardputer 从"几个功能"变成一个有导航的助手，设备上的改动都在固件里。它回应的是用户 10-21 的反馈：要有一个界面，每个功能做成一个应用并且有快捷键直达；要有一个常驻的菜单，忘了快捷键时能提醒；锁屏很重要。计划和取舍见 docs/13-assistant-v2-plan.md。

这一版还带上了 v0.4.1 的协议和 Mac 侧，以及固件里对应的编解码（见"也带上了：v0.4.1 的协议和 Mac 侧"）；设备界面还不用它们。协议 v0 全部只新增：新旧固件和新旧 cpad 可以任意搭配。WhisperWoof 不用改。

### 定下的事（docs/13 §18 的默认值）
1. **声音**：v0.3.1 起设备不出任何声音。这一版不加静音键，也不加音量档位，因为没有声音可调。菜单"控制"页有一行只读的"声音 关（录音不出声）"。
2. **键位**：Opt+H 改成主页，项目看板挪到 **Opt+P**；新增 **Tab** 菜单和 **Opt+L** 锁屏；Opt+M 仍是系统。只有 Opt+H 一个键改了含义。
3. **锁屏时的 G0**：先点一下 G0 亮出锁屏卡片，卡片亮着时再按住 G0 才录便条；屏幕黑着时按住 G0 只亮屏。开会时 G0 永远是加 ★。
4. **会议确认框的文案不改**：仍是 v0.3.1 的"开始会议录音？ / 请先告知在场的人 / Enter 开始 ` 取消"。docs/13 §7.4 提过一版新文案，用户还没有同意，这一版不用。
5. 只用单键和两键组合（`test_keymap_static` 检查）。

### 新功能
- **主页启动器（Opt+H）**：
  - 3×3 的格子：P 项目、I 等你、R 开会、N 记一条、Q 排队给 AI、S 开 session、M 系统、L 锁屏、Tab 菜单。
  - 在主页上直接按格子上的字母，等于按 Opt+那个字母；1–9 打开第 N 个项目页；`;` `.` `,` `/` 在格子间移动，Enter 打开选中的格子。
  - 格子自己不执行任何事，只是"替你按那个键"，所以效果和直接按快捷键完全相同。
  - 标题写日期（"主页 · 10/21 周三"，时间未知时只写"主页"）；项目格显示"跑N"，等你格显示"!N"；下面一行是最急的一条"等你"（项目/名字和等了多久，不显示正文），没有时写"没有等你的 session"。
  - 主页是根页面：从任何应用的第一层按返回，都回到主页。从项目看板总览打开的项目页是第二层，按返回先回到总览。
- **Tab 常驻菜单**：
  - 任何页面都能按 Tab 打开，便条进行中和锁屏时除外。三页：**本页**（这一页能按的键）、**去哪**（全局键，主页、项目、等你、项目页、系统排在前面）、**控制**（锁屏，以及只读的声音、电池、SD 卡、Mac 链路）。
  - `;` `.` 选行，`,` `/` 换页，Tab 或 `` ` `` 关掉。选中一行按 Enter：菜单关掉，再替你按下这一行左边写的键，效果和直接按相同。一组键的行（如 `Opt+1-9`）只是说明，按 Enter 不执行。
  - Tab 再按字母，等于按 Opt+那个字母（"本页"和"去哪"上都行；"控制"页上是这一页有那一行时），所以 Tab、P 两下就到项目看板。
  - 在采集页、确认框、会议页上打开时只有"本页"和"控制"，"本页"上的字母被菜单吃掉，不能从菜单跳到别处，草稿和正在录的音都不受影响。
  - 采集页的"放弃已输入的内容？"按确认框处理：菜单里写的是 Enter 放弃草稿、`` ` `` 和 Fn+` 返回编辑，Opt+L 无效。
  - 按住 Backspace 关掉菜单时，这次按住的连删不会接着删草稿或退出页面。
  - 菜单里按 G0：菜单关掉，G0 照常起作用（开会时加 ★，不开会时记一条或录便条）。
- **Opt+L 锁屏**：
  - 屏幕马上熄灭，键盘锁住，**插着 Mac 也熄屏**；用电池、屏幕已经因为 60 秒没按键熄灭时按，也直接锁上。锁屏前的页面、采集页的草稿、正在开的会都留着，录音不停。
  - 解锁：先按 Opt+L（亮出锁屏卡片，开一个 3 秒窗口），再在窗口内按 Enter，回到锁屏前的页面。
  - 锁住时点一下 G0，亮出锁屏卡片 3 秒；卡片亮着时按住 G0 录一段便条（锁在草稿上也一样，草稿不动），麦克风打开前左上角是"● 准备"，录完回到黑屏锁定。屏幕黑着时按住 G0 只亮屏，这一次按住到松开都不录。开会时 G0 是加 ★。其他任何键都不起作用，也不点亮屏幕。
  - 锁屏卡片只显示时间、日期、电量、等你的数量、待传的录音段数和 ↑N，不显示项目名、session 名或正文；锁住时不弹提示。
  - **锁屏不是安全锁**：没有 PIN，只防口袋里误触、不让旁人看到内容（见 SECURITY.md）。
- **录音时 ● 永远看得见**：录音中（Cue、Recording、EndConfirm、Finishing）背光最暗只到"调暗"，并且画出 ● 和计时，锁屏、菜单打开、弹出提示时都一样。锁屏时开会，屏幕调到最暗，左上角只显示"●42:10 ★2"这样一行。v0.3.1 去掉提示音以后，屏幕是唯一的提示，这条规则更重要。
- **提示栏**：主页、项目看板、等你、系统页、采集页和会议页的提示栏最右边固定写"Tab菜单"；确认框的提示不变。采集页的提示为了放下它，去掉了"Opt 0-9 目标"（改目标项目写在菜单的"本页"里）。
- **测试固件**：`debug.state` 新增可选字段 `ui{menu, locked}`；菜单打开时 `overlay` 仍报菜单下面的那一层。HIL 用它判断菜单是否打开、设备是否锁住。正式固件没有任何 `debug.*`。
- 固件版本报 `cpa-fw/0.4.0`。

### 也带上了：v0.4.1 的协议和 Mac 侧（设备界面还没有）
v0.4.1 的录音应用和采集去向先做了协议、cpad 和固件的编解码，一起合进了这一版。设备上还没有任何界面用到它们：固件不发 `rec.*`、不发 `dest`，收到主机 `hello` 里的 `caps.recs` / `caps.todo` 也不做任何事。录音应用、去向选择等界面留给 v0.4.1。
- **协议 v0，只新增**（protocol/README 第 20 条，docs/13 §12.2）：
  - 主机 `hello` 新增可选的 `caps.recs`、`caps.todo`，以及本机的 `host_id` 和 `host_label`。
  - 笔记（`outbox.item`）和 `file.items` 的每一项可以带 `dest`。v0.4.1 只用 `"todo"`；省略、`null`、`"daily"` 都是今日笔记，不认识的值也按今日笔记处理。
  - 新消息 `rec.list` → `rec.items`（录音历史，每页最多 6 条，翻页用 cpad 给的不透明 `cursor`）和 `rec.act` → `ack`（加 ★、去掉 ★、归到项目、隐藏，没有删除）。
  - `rec.items` 是唯一可以超过 256 B 的主机回复，仍受单行 2048 B 限制。录音文件契约 v1 和 `manifest.json` 一字不改。
- **cpad**：
  - `hello` 带上 `caps.recs`、`caps.todo` 和 `host_id`：第一次运行时随机生成，存在 `$CPA_HOME/host_id`，不写进日志。`host_label` 可选，来自配置。
  - `dest` 为 `todo` 的笔记，以及第 0 段带 `dest:"todo"` 的便条，在今日笔记里写成 `- [ ]` 一行。
  - 能回答 `rec.list`（按开始时间新的在前，不只按 MonoId 排）和 `rec.act`。加 ★、归项目、隐藏只追加 `rec.edited`、`rec.hidden` 事件，不碰录音文件和 `manifest.json`。
  - `cpa rec ls` 显示 ★ 和项目，加 `--hidden` 才列出隐藏的录音；新增 `cpa rec unhide <sid>`。
- **固件**：编解码能读写上面所有新字段和新消息（`lib/protocol/codec_rec.cpp`，`rec.items` 直接解码进消息里固定 6 行的页，消息不变大），运行时和界面都没有改。主机不发这些字段时，编码结果和以前逐字节相同。

### 修复
- **录音传到 Mac 更快了**（#43）：传输时每收到一块数据都会重画整个屏幕（每秒约 20 次，重画时不回应传输），v0.4.0 的主页又比原来的项目看板画得慢，会议录音从 336 KB/s 掉到 263 KB/s。现在只是"最近一次收到"的时间变了就不重画（只有系统页显示它，每秒刷新一次照旧）。真机实测会议录音约 **513 KB/s**，比 v0.3.2 快约 50%，1 小时录音约 3.5 分钟传完。

### 按键变化
| 按键 | v0.3.1 | v0.4.0 |
|---|---|---|
| Opt+H | 项目看板 | 主页（启动器） |
| Opt+P | 没有 | 项目看板 |
| Tab | 没有 | 菜单 |
| Opt+L | 没有 | 锁屏；锁住时是解锁的第一步 |
| Enter（锁住时，按 Opt+L 后 3 秒内） | — | 解锁 |

完整的按键表见 docs/04-prd.md §8 和 README 的"按键"一节。

### 没有变的
- 其他全局键：G0 记一条、按住 G0 录便条、Opt+1–9、Opt+I、Opt+M、Opt+N/Q/S、Opt+R、返回键。
- 会议确认框：文案、400 ms 防误触、`consent:"ack"` 写进 `.M` 和 `manifest.json`。录音手势、5 分钟和 3 小时的上限、★ 标记、录音全程不出声。
- 协议 v0 只新增（测试固件的 `debug.state.ui`，以及上面 v0.4.1 的字段和消息）；录音契约 v1、`file.*` 传输不变。
- 导航栈最多 4 层。

### 已知问题
